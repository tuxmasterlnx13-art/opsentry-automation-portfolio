# Audit Reporting & Notifications

Daily and weekly reporting automation for operational audit results. Report generation is separated from delivery configuration and browser/session state.

## Capabilities

- Deterministic summaries from validated inputs.
- Daily and weekly report formats.
- Automated tests for report behavior.
- Optional notification adapters configured outside source control.

The public edition omits recipient lists, message history, browser profiles, generated reports, and all live configuration.
