# Security Policy

## Supported version

Only the latest commit on the default branch is supported during the release-candidate phase.

## Reporting a vulnerability

Do not open a public issue for credentials, customer data exposure, authentication bypasses, or write-path vulnerabilities. Use GitHub's private vulnerability reporting feature. Include the affected project, impact, reproduction steps using synthetic data, and a proposed mitigation if available.

## Operational warning

The integrations in this repository are examples for authorized environments. Operators are responsible for access approval, vendor terms, backups, pilot scope, and change management. Never commit session files or production exports.
